# keymagic-rs

An engine-first Rust reimplementation of the KeyMagic input method, following the [KeyMagic Rust Lab](https://01a1ff77-4137-7a69-a0fa-36ed3fcc921d.arena.site/). The Cargo workspace and crate entry points are initial placeholders only: no input method, compiler, GUI, platform adapter, or packaging functionality is implemented yet. The workspace has not yet been validated by Rust tooling.

Read [AGENTS.md](AGENTS.md) and [docs/PLAN.md](docs/PLAN.md). Routine Rust tooling runs on a self-hosted GitHub Actions runner; cross-platform and release verification use GitHub-hosted runners. No CI result is available until the repository and runner can be accessed.
