# Changelog

## Unreleased

- Keyboards: cards show the icon, hotkey and active choice; the options menu sets the hotkey, renames, shows the file, moves, and removes after confirmation. Filter and Open folder added.
- Tester: a diagnostics pane shows the last key, whether it was handled, the output, the composing text, and the rule and source line behind it. Record case saves the typed input and output to `<keyboard>.cases.toml`.
- Editor: KMS syntax highlighting; the layout preview shows Shift and AltGr layers while those keys are held; the glyph picker includes Myanmar Extended-A and -B letters.
- Settings: each integration panel has a status dot; Open settings opens the Windows or macOS input settings.
- Tray: the icon is accent while a keyboard is active and grey otherwise.
- About: this changelog.
